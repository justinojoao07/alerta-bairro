# AlertaBairro

Alerta comunitário de enchentes, rua a rua, para o Jardim Pantanal e região (zona leste de São Paulo). Moradores relatam o nível da água, o sistema calcula o risco e o bairro recebe o alerta. Projeto da Global Solution 2026/2 (CitizenTech, FIAP).

## Tecnologias
HTML5 semântico, CSS3 (variáveis e media queries) e JavaScript puro. Sem frameworks, bibliotecas ou templates.
